# 🎮 GameLearn Hub

A website for young gamers (10-25) to learn game design and find cheat codes.

## ✨ Features

- 🎨 **Game Design Tutorials** — Beginner to Advanced
- 🔑 **Cheat Codes** — GTA V, Minecraft, FIFA 24, Free Fire, Roblox, PUBG
- 🧠 **Interactive Quiz** — Test your game design knowledge
- 🕹️ **Mini Game** — Memory Card Game
- 📊 **Progress Tracker** — Track your learning progress
- 🌙 **Dark/Light Mode** — Toggle between themes
- 📬 **Newsletter** — Subscribe for updates
- 📱 **Responsive Design** — Works on all devices
- 📖 **Step-by-Step Guide** — Cheat codes kaise use karein

## 🚀 Deploy on Netlify (Free)

### Method 1: Drag & Drop (Easiest)
1. Go to [netlify.com](https://netlify.com)
2. Sign up / Login
3. Drag your `game-learn-hub` folder to the deploy area
4. Done! 🎉 Your site is live

### Method 2: GitHub
1. Create a GitHub repository
2. Upload all files
3. Go to Netlify → "Add new site" → "Import from Git"
4. Select your repo → Deploy
